## Результаты

Разбиение на train/test не вводится: используются полные таблицы истинности,
по четыре объекта на задачу. Порог класса 1: вероятность **≥ 0.5**.
Инициализация, шаги и число эпох точно соответствуют методичке; случайных чисел нет.

| Задача | Архитектура | Параметров | Эпох | Шаг | Начальная BCE | Итоговая BCE | Accuracy |
|---|---|---:|---:|---:|---:|---:|---:|
| OR | 2 → 1, sigmoid | 3 | 300 | 0.5 | 0.720019843 | 0.062167395 | 1.0 |
| AND | 2 → 1 → 1, tanh / sigmoid | 5 | 300 | 0.3 | 0.693386131 | 0.022805302 | 1.0 |
| XOR | 2 → 2 → 1, tanh / sigmoid | 9 | 500 | 0.5 | 0.697489514 | 0.025026250 | 1.0 |

Все критерии выполнены: OR BCE < 0.1, AND BCE < 0.05, XOR BCE < 0.03.
Итоговая BCE посчитана свежим прямым проходом **после** последнего обновления.
В `history.csv` и списках `*_losses` сохранена BCE **до** обновления эпохи,
как в исходном задании: последние значения 0.062363748, 0.022928442 и 0.025122786.

В порядке входов `[0,0]`, `[0,1]`, `[1,0]`, `[1,1]` получены вероятности:

| Задача | p(0,0) | p(0,1) | p(1,0) | p(1,1) | Метки |
|---|---:|---:|---:|---:|---|
| OR | 0.132004 | 0.947852 | 0.948297 | 0.999544 | 0, 1, 1, 1 |
| AND | 0.003719 | 0.019203 | 0.019204 | 0.952454 | 0, 0, 0, 1 |
| XOR | 0.018893 | 0.967634 | 0.968429 | 0.015921 | 0, 1, 1, 0 |

Градиенты всех **17 параметров** до обучения проверены центральной разностью
с шагом `1e-6` и допуском `1e-5`. Наибольшая абсолютная ошибка — около `1.23e-10`.
У AND начальный градиент первого входного веса скрытого нейрона равен нулю
из-за компенсации вкладов объектов; после обучения все пять градиентов ненулевые.
Общие веса OR дополнительно сверены с аналитической формулой градиента средней BCE.

## Запуск

### Ноутбук

Кнопка **Open In Colab** открывает самостоятельный ноутбук. Выберите
**Среда выполнения → Выполнить всё**. Загружать репозиторий и устанавливать
вычислительные зависимости не нужно.

Локально требуется Python 3.10+; проверено на Python 3.13.2.
Откройте терминал в `lab5`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\jupyter.exe lab student_vector_binary_classification_lab.ipynb
```

В Linux/macOS замените `.\.venv\Scripts\python.exe` на `.venv/bin/python`,
а путь к Jupyter — на `.venv/bin/jupyter`.
Основной код можно установить через `python -m pip install -e .`;
пакеты Jupyter и pytest входят только в дополнительную группу `dev`.

### Эксперимент без внешних зависимостей

```powershell
python experiment.py
```

Команда заново обучает три модели, проверяет критерии и записывает JSON/CSV
в `artifacts` рядом со скриптом. Работает из любого текущего каталога.
В `results.json` порядок весов совпадает с `parameters()`: скрытые веса
по нейронам, затем выходные; в каждой группе первым идёт вес смещения.

### Тесты и пересборка

После установки `.[dev]`, находясь в `lab5`:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe build_notebook.py
```

Ожидается `20 passed`. Тесты проверяют цепное правило, ветвление графа,
повторный `backward()`, явный путь смещения, накопление общих весов,
градиенты всех моделей, заданные запуски обучения и сохранение полной симметрии
нейронов. Сборщик использует Python, которым запущен, и временное локальное ядро
в `tmp`; глобальная регистрация Jupyter-ядра не требуется.
Пересборка берёт структуру из сохранённого ноутбука, определения — из модуля,
вновь выполняет все ячейки и обновляет результаты эксперимента.

## Источники и границы результата

Учебные материалы: Dmitry Vlasov, «Лабораторная работа: векторный вход и бинарная
классификация» и «Теория: векторный вход и бинарная классификация», 2026,
CC BY-NC-ND 4.0. Предоставленные PDF сохранены без изменений и содержат сведения
об авторе и лицензии; код следует учебным блокам. Исходный класс `Value` сохранён
полностью, как в предыдущей лабораторной.

Четыре точки служат проверкой механизма обучения и выразительности модели;
их accuracy не является оценкой обобщения на прикладном датасете.
Sigmoid и BCE намеренно собраны из операций эталонного `Value`, как в задании.
Для произвольно больших по модулю логитов эта учебная запись может приводить
к переполнению `exp` или `log(0)`; фиксированные эксперименты этой проблемы не имеют.
