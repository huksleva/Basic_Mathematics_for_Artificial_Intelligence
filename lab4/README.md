## Полученный результат

В исходных 1372 записях обнаружены 24 полных дубликата. Они удалены до разбиения,
чтобы одинаковые записи не попали в обучение и тест. Получено 1348 уникальных
объектов: train=809, val=270, test=269; разбиение стратифицированное около 60/20/20.
Стандартизация обучается только на train. Индексы частей и параметры scaler сохранены.

Сеть: **4 → 32 → 16 → 1**, ReLU / sigmoid, 705 параметров. Batch=32, lr=0.03,
momentum=0.9, L2=0.0001, максимум 150 эпох, patience=20, min_delta=0.00001.
Seeds: split=42, model=42, shuffle=43. Ранняя остановка включена, но не сработала;
восстановлены веса с минимальной val BCE на эпохе 149.

Порог выбирается по максимальному F1 на val. При равенстве выбран ближайший к 0.5,
затем меньший; результат **τ=0.5**. Test оценивается после фиксации модели и порога.

| Test, 269 объектов | Значение |
|---|---:|
| Accuracy | 1.0000 |
| Precision / Recall / F1 | 1.0000 |
| ROC-AUC | 1.0000 |
| Average Precision | 1.0000 |
| BCE | 0.000445806 |
| TN / FP / FN / TP | 147 / 0 / 0 / 122 |

AP используется как ступенчатая сумма precision по приращениям recall, не как
трапециевидная площадь PR. Результат относится к одному датасету и разбиению;
он не гарантирует отсутствие ошибок на данных из новых источников.

## Запуск

### Google Colab

Нажмите кнопку **Open In Colab** вверху и выберите **Среда выполнения → Выполнить всё**.

### Локально

Python 3.10 или новее. Проверенный запуск: Python 3.13.2, CPU.
Откройте терминал в папке `lab4`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe experiment.py
```

Чтобы открыть ноутбук, выберите интерпретатор этого окружения в Jupyter или IDE.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q tests
.\.venv\Scripts\python.exe build_notebook.py
.\.venv\Scripts\python.exe build_report.py
```

`build_notebook.py` использует локальный Python из `.venv/Scripts` и временное
ядро внутри `tmp`, без глобальной установки ядра. `build_report.py` использует
шрифты Arial/Consolas из Windows и DejaVu Sans из Matplotlib.
Для запуска в Linux/macOS используйте `.venv/bin/python` для эксперимента и тестов;
при пересборке отчёта нужно заменить пути к шрифтам, при пересборке ноутбука - путь к Python.

## Проверка математики и протокола

Центральной разностью проверены все 47 параметров небольшой сети для ReLU и tanh,
с L2 и без неё. Точки проверки ReLU выбраны вдали от излома z=0.
Максимальная абсолютная ошибка в эксперименте меньше 1.5e-10.
Тесты также проверяют однократное усреднение по батчу, устойчивость BCE при больших
логитах, разбиение без пересечений, train-only стандартизацию, равные оценки в AUC/AP,
выбор порога, восстановление раннего лучшего чекпойнта и совпадение прогнозов загруженной модели.

История `loss`/`val_loss` хранит BCE без L2; `objective` хранит train BCE с L2.
Accuracy в истории считается при 0.5. История относится к весам каждой эпохи;
итоговые метрики относятся к восстановленной лучшей модели.
