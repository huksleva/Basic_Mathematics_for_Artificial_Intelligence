```

## Запуск

```

## Что выполнено

1. Суммы по индексам, матричное умножение и `einsum`.
2. Производные одной переменной и конечные разности.
3. Частные производные, градиент и полный дифференциал.
4. Производная по направлению и полная производная.
5. Якобиан, JVP, VJP и цепное правило.
6. Гессиан и классификация кривизны.
7. Матричное дифференцирование и матричный градиент.
8. Сквозное вычисление функции, аналитические градиенты и их поэлементная проверка.
9. Градиентная оптимизация для трёх значений шага.
10. Итоговая карта понятий и таблица операторов.

## Проверки

В ноутбуке сохранены результаты выполнения кода, численные ошибки и графики. Для сквозной функции отдельно проверяются все элементы `W` и `b`.
