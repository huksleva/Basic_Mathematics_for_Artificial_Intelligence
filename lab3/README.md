## Что реализовано

**Часть 1. Класс `Value`**
- Хранение `data`, `grad`, `parents`, `op`, `_backward` в каждой вершине графа
- Прямой проход: `__add__`/`__radd__`, `__mul__`/`__rmul__`, `__neg__`, `__sub__`/`__rsub__`, `__pow__`
- Элементарные функции: `sin`, `exp`, `log`, `tanh`
- Обратный проход `backward()`: топологическая сортировка через рекурсивный обход
  `build`, обнуление градиентов, `self.grad = 1.0`, вызов `_backward()` в обратном
  топологическом порядке
- Ручная трассировка трёх локальных шагов обратного прохода для графа
  `J = tanh(a*b + a)`
- Проверка градиента центральной разностью

**Часть 2. `TanhNeuron`**
- `z = w*x + b`, `ŷ = tanh(z)`
- Среднеквадратичная ошибка (MSE) по 6 объектам, сверка аналитического и численного
  градиента по `w` и `b`
- Градиентный спуск на 80 эпохах: финальная ошибка < 0.03, точность классификации = 1.0

Все контрольные точки из чек-листа методички (`lab_guide.pdf`, раздел «Чек-лист перед
сдачей») пройдены — см. вывод ноутбука.

### Как отдельный модуль

```python
from autograd_lab import Value, TanhNeuron, train

a = Value(2.0)
objective = a * a + a
objective.backward()
print(a.grad)  # 5.0

neuron = TanhNeuron(weight=0.0, bias=0.0)
losses = train(neuron, [-3, -2, -1, 0, 1, 2], [-1, -1, -1, -1, 1, 1])
print(losses[-1])
```

## Диагностика (кратко, по методичке)

| Симптом                                            | Причина                                                                                          |
|----------------------------------------------------|--------------------------------------------------------------------------------------------------|
| Для `a*a + a` градиент не 5                        | в `_backward` используется `=` вместо `+=`, либо перепутаны `self.data`/`other.data` в умножении |
| Все градиенты нулевые                              | не выставлен `self.grad = 1.0` перед обходом `reversed(topo)`                                    |
| Неверный порядок вычислений                        | вершина добавлена в `topo` до родителей — нарушен инвариант `build`                              |
| Loss не уменьшается                                | `parameter.data` изменён до `loss.backward()`, либо `-=` заменён на `+=`                         |
| Градиент удваивается на втором вызове `backward()` | не выполняется обнуление `grad` в начале `backward()`                                            |
